# Tunnova — project identity

- **Official working name:** Tunnova
- **Tagline:** Connect freely. Stay in control.
- **Mission:** Make secure Linux connectivity understandable and easy to use without requiring users to hand-edit network routes or system services.
- **Official repository:** https://github.com/sewminakatugaha/tunnova
- **Python package:** `tunnova`
- **Proposed desktop app ID:** `org.tunnova.Tunnova` (subject to review before distribution)
- **Current status:** pre-alpha foundation, offline link inspection only, no VPN connection yet.
- **Values:** accessibility, safe failure, honest status reporting, transparent operation, privacy-preserving logs, cross-distribution testing.
