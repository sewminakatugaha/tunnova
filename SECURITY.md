# Security policy

**No security guarantees yet: the current app does not establish a VPN.**

Do not submit real access credentials, VLESS subscription links, configuration secrets, or unredacted logs in GitHub issues or pull requests.

Until we establish a dedicated private vulnerability reporting channel, avoid posting exploitable vulnerability details publicly; contact maintainers through a private channel identified in the repository's eventual GitHub Security settings. This starter archive does not claim a configured response address.

Once published, maintainers should enable GitHub Private Vulnerability Reporting, document supported versions, and publish a response process before issuing functional networking releases.
